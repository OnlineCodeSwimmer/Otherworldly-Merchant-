I prefer to be credited as 'Matthew Ashworth', though 'Matseb2611' is also fine.

This pack contains a set of various floor tiles.
There are 9 different designs, each one coming in 2 colour varieties, and these
in turn, each come in 12 variations - the original tile (located in top left
of every set), plus 11 versions with cracks, breakages, dirt, and other types
of wear and tear, so to give some variety to your game's floor areas.

This gives a total of 216 different tiles!

Two different sizes have been provided for the tiles:
48 x 48 pixels per tile and 32 x 32 pixels per tile.

These floor tiles are highly suitable for any top down view 2D game, although
you can use them for any purpose within any type of game really.
